# 공연 쇼츠 편집기 (shorts-maker)

공연 촬영 영상을 구글 드라이브에서 불러와 세로 쇼츠(1080×1920)로 편집하는 윈도우용 프로그램.

## 업데이트 배포 방법

설치된 프로그램은 켤 때마다 이 저장소의 `release.json`을 확인한다.

- `app.zip` : 프로그램 본체(`app/` 폴더) 압축
- `release.json` : `{"version": "x.y.z", "zip": "<app.zip 주소>"}`

새 버전을 올릴 때는 `app/VERSION`을 올린 `app.zip`과, 같은 버전 번호를 적은 `release.json`을 함께 교체하면 된다.
서버 노트북은 다음 실행 때 자동으로 새 버전으로 바뀌고, 새 버전이 안 켜지면 이전 버전으로 되돌린다.

`app.zip`에는 `app/update.json`을 넣지 않는다. 노트북마다 자동 업데이트를 켜고 끈 설정이 다를 수 있어서, 1.6.2부터 프로그램이 켜질 때 이전 버전 폴더(`app_old`)의 `update.json`을 그대로 가져온다(없으면 기본값으로 켜짐). 자동 업데이트를 끄려면 그 노트북의 `app/update.json`을 `{"url": ""}`로 두면 된다.

설치 꾸러미(파이썬·ffmpeg 포함)는 용량이 커서 이 저장소에는 올리지 않는다.
